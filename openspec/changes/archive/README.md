# 历史变更归档

本目录收录 OpenSpec 引入前由 Superpowers 工作流产生的设计与计划（原 `docs/superpowers/`），内容保持原样，仅调整位置：

- `docs/superpowers/specs/<日期>-<名称>-design.md` → `<日期>-<名称>/design.md`
- `docs/superpowers/plans/<日期>-<名称>.md` → `<日期>-<名称>/tasks.md`

例外：`2026-07-09-bundled-config/tasks.md` 原为 `2026-07-09-bundled-config-sanitization.md`；`2026-09-24-product-alignment-maintenance-baseline/design.md` 原为 `2026-09-24-product-alignment-maintenance-baseline.md`。

文档内部引用的 `docs/superpowers/...` 路径与 `superpowers:*` 技能为历史记录，按上述规则对应即可。仍然生效的规则已提炼到 `openspec/specs/`：

- `product-ownership` ← product-alignment-maintenance-baseline
- `product-default-policy` ← product-default-policy
- `cross-host-product-contract` ← cross-host-product-contract
