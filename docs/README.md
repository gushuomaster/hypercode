# HyperCode 文档索引

本目录收录 HyperCode(基于 OpenCode 的品牌化 fork)的工程文档,按用途分四类。

## 📐 规范(必读)

长期有效的原则与规则,做任何上游同步/品牌化前应先读。

- [上游同步工作流总纲](规范/上游同步工作流总纲.md) — **核心**。自动 upstream sync 的完整闭环:读状态 → 隔离 worktree → 合并上游 → 三组 diff 影响分析 → 报告 → 人工决策。定义了 4 种终态分类。
- [上游同步与品牌化规范](规范/上游同步与品牌化规范.md) — 差异维护原则、可脚本化边界、禁止被上游恢复的项、高风险冲突文件清单。

## 🛠 操作手册(执行参考)

具体可执行的步骤与命令。

- [上游同步操作流程](操作手册/上游同步操作流程.md) — upstream 同步的 SOP:同步前检查 → merge → 冲突处理 → rebrand → 构建 → VSIX 验收。
- [构建与交付规范](操作手册/构建与交付规范.md) — CLI 二进制与 VSIX 的构建命令、smoke test、产物命名约定。

## 📋 报告(参考)

品牌化工作的规划与完成记录。

- [品牌化审计基线](报告/品牌化审计基线.md) — 品牌化前的基线审计:opencode 引用按风险分级(A/B/C),全局替换的边界依据。
- [品牌化完成报告](报告/品牌化完成报告.md) — 品牌化阶段完成情况:已覆盖范围、保留的 OpenCode 引用及理由。

## 🗄 归档(历史快照,带日期)

一次性的、带时间戳的记录,仅供历史参考,不再更新。

- [阶段性汇报_20260616](归档/阶段性汇报_20260616.md) — 2026-06-16 项目进度快照:CI 闭环状态、下一步优先级。
- [上游同步影响报告_20260611](归档/上游同步影响报告_20260611.md) — 2026-06-11 一次隔离 worktree 同步验证的结果:三组 diff 数据、24 个真实受影响文件、VSIX 验收结果。

## 我该看哪篇?

| 我要做的事 | 看这些 |
|------|------|
| 第一次接手 upstream 同步 | 先读 [工作流总纲](规范/上游同步工作流总纲.md),再读 [同步与品牌化规范](规范/上游同步与品牌化规范.md) |
| 执行一次 upstream 同步 | 按 [上游同步操作流程](操作手册/上游同步操作流程.md),冲突时查 [同步与品牌化规范](规范/上游同步与品牌化规范.md) |

| 了解某次同步的历史结果 | [归档](归档/) 下带日期的报告 |
