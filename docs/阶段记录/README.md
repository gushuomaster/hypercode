# HyperCode 阶段记录

本目录用于保存带时间点、带基线、带验证结果的历史记录。

它负责沉淀：

- 某个阶段开始时的审计基线
- 某次同步、验证或分析的专项记录
- 某个阶段结束时的总结与汇报

它不负责：

- 定义长期有效的规则和判断口径
- 充当具体执行步骤的操作手册
- 保存尚未收口的临时草稿

如果你要看：

- 长期规则与职责边界：查看 [docs/规范](../规范)
- 具体执行步骤与构建命令：查看 [docs/操作手册](../操作手册)
- 某次历史事实、基线、统计、验证结果：查看本目录

## 使用建议

- 需要回看“某阶段开始时我们是怎么判断的”，优先看基线记录。
- 需要回看“某次同步或验证到底发生了什么”，优先看专项记录。
- 需要回看“某个阶段推进到哪一步、下一步做什么”，优先看阶段汇报。

## 后续新增记录的放置原则

- 基线记录：记录某阶段启动时的事实基线和初始判断。
- 专项记录：记录某次同步、构建、验证、影响分析或验收的现场证据。
- 阶段汇报：记录某个阶段的结果总结、风险评估和推进计划。
